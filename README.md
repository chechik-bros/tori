## מתחילים

- **[SETUP.md](SETUP.md):** הקמה, צעד אחר צעד
- **[docs/github.md](docs/github.md):** איך עובדים ביחד עם GitHub
- **[docs/whatsapp.md](docs/whatsapp.md):** הקמת וואטסאפ ב־Meta
- **[AGENTS.md](AGENTS.md):** כללי הפרויקט (גם ל־Claude ול־Cursor)

## פקודות

npm install      # once, after cloning
